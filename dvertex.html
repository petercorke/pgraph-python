__init__(coord=None, name=None)

Create a vertex object

Parameters:

  • coord (array-like, optional) – coordinate of the vertex for an embedded graph, defaults to None

  • name (str, optional) – vertex name, defaults to None

Creates a vertex but does not add it to a graph – use _BaseGraph.add_vertex() for that.

>>> from pgraph import UVertex
>>> v1 = UVertex(coord=[0,0], name='v1')
>>> print(v1)
[v1]

connect(other, **kwargs)[source]

Connect this vertex to another with a directed edge

Parameters:

  • other (BaseVertex subclass or Edge) – vertex to connect to, or an existing edge to attach

  • kwargs (Any) – arguments passed to BaseVertex.connect(), ignored if other is an Edge

Raises:

TypeError – other is neither a BaseVertex nor an Edge

Returns:

the edge connecting the vertices

Return type:

Edge

Unlike the undirected-graph counterpart, the new edge is added only to this vertex’s edge list – it is only discoverable from the start of the directed edge.

>>> from pgraph import DVertex, Edge, DGraph
>>> g = DGraph()
>>> v1 = g.add_vertex(coord=[0,0], name='v1')
>>> v2 = g.add_vertex(coord=[1,1], name='v2')
>>> v1.connect(v2, cost=1.414)
Edge{[v1] -- [v2], cost=1.414}
>>> print(v1.edges())
[Edge{[v1] -- [v2], cost=1.414}]
>>> print(g.edges())
{Edge{[v1] -- [v2], cost=1.414}}
>>> print(g)
DGraph: 2 vertices, 1 edge, 1 component

Copy a vertex

Returns:

BaseVertex subclass

If cls is given, cls.vertex_copy(self) is used to create a vertex of the appropriate subclass for that graph type, otherwise a vertex of the same class as self is created directly.
