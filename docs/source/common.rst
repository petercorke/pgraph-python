Common methods
===============

:class:`DGraph`/:class:`UGraph` and :class:`DVertex`/:class:`UVertex` share
almost their entire interface, defined once on their common base classes
(:class:`_BaseGraph`, :class:`BaseVertex`). This section documents that
shared interface by task rather than by class; see :doc:`dgraph`/
:doc:`ugraph` and :doc:`edges_vertices` for what's specific to directed vs.
undirected.
